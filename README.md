# SkyGuard: Securing Drone GPS via Cross-View Aerial-Satellite Matching

This repository contains the code used for our cross-view aerial-satellite matching based GPS spoofing detection experiments.

## Offset Dataset

The offset satellite image dataset constructed for the GPS spoofing offset experiment is available on Google Drive:

[Download the offset dataset](https://drive.google.com/file/d/1pu1HHgw2xBOAmBjzwo6ac-zNH0FbqPVz/view?usp=drive_link)

The dataset includes satellite images with different simulated GPS offsets, including 10 m, 50 m, and 100 m shifts in the east, west, north, and south directions.
